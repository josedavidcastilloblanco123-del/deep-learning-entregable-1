This repository is for an academic Deep Learning assignment. Read `PROJECT_CONTEXT.md` and `docs/Entregable1DeepLearningProject_extracted.txt` before altering code or proposing experimental methods.

- The **34-page project specification** is authoritative. The 3-page RNN document is a different assignment.

- For any new model, dataset split, or metric choice, document rationale and correspondence with rubric.
- Do not invent experiments, statistical significance, research citations, or training performance.
- Do not claim the baseline architecture selection is finalized until literature extraction/frequency table is done.
- Keep experiments deterministic as far as practical; log seeds, packages, configs, CPU/GPU, timing and preprocessing decisions.
- Keep the test set untouched until the evaluation protocol is frozen.
- Prefer small, modular, rerunnable Python / PyTorch scripts and a Jupyter Book-compatible report.
- Ask before making the repository public or committing copyrighted/restricted third-party datasets. The repo is currently public.
